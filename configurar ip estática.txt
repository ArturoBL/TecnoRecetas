3. Buscamos el archivo de configuración .yaml con:
	/etc/netplan
	
4. Cambiamos el archivo:
   sudo nano /etc/netplan/50-cloud-init.yaml
   
   
   network:
    renderer: networkd
    ethernets:
        enp0s3:
            addresses:
              - 192.168.3.36/24
            nameservers:
              addresses: [4.2.2.2,8.8.8.8]
            routes:
              - to: default
                via: 192.168.3.1
    version: 2
	
	Detalle de cambios:
		- se agrega renderer, se pone ip estática, se pone nameserver, se pone gateway (routes)
		
		
5. Actualizamos la configuraciòn:
	sudo netplan apply
